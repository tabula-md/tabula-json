# Contributing

Thanks for helping improve Tabula.md JSON.

## Before You Start

- Use GitHub Issues for bugs and focused proposals.
- Keep pull requests limited to one reviewable concern.
- Discuss storage-driver, retention, route-contract, or security-boundary
  changes before writing code.
- Do not include Export links, keys, plaintext content, credentials, or
  snapshot payloads in issues, logs, screenshots, or fixtures.
- Report vulnerabilities privately through [Security](SECURITY.md).

## Development

```sh
npm install
npm test
npm run build
```

## Pull Requests

Explain why the change is needed, what changed, and how you verified it.
Include risk notes only when they help review storage or security behavior.
